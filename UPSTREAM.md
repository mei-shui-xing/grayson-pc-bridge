# Upstream provenance

AI Desktop Control Bridge is a derivative fork of [Desktop Commander MCP](https://github.com/wonderwhy-er/DesktopCommanderMCP).

## Recorded fork base

- Upstream package: `@wonderwhy-er/desktop-commander`
- Upstream version at the recorded fork point: `0.2.46`
- Upstream repository: `https://github.com/wonderwhy-er/DesktopCommanderMCP.git`
- Recorded base commit: `1eccc8b`
- Upstream license: MIT

The upstream Git history, authorship, and root MIT license are intentionally retained. The Windows UI sidecar, launcher integration, safety gates, and fork-specific documentation are changes maintained by AI Desktop Control Bridge contributors.

## Distribution boundary

- This fork is distributed from its own GitHub repository as source code.
- It does not publish using the upstream npm package name.
- Upstream installation commands install upstream Desktop Commander, not this Windows control fork.
- Changes must not be pushed directly to the upstream remote unless they are independently prepared as an appropriate upstream contribution.

For upstream features and documentation that are not specific to this fork, consult the current upstream repository. Upstream documentation may change independently and should not be treated as installation instructions for this Alpha.
