Grayson电脑助手（Windows）
========================

1. 想让 ChatGPT 操作电脑时，双击“启动电脑助手.bat”。
2. 第一次使用如弹出浏览器授权页，请完成一次授权。看到“绿色：允许远程控制”和“现在可以让 ChatGPT 操作电脑”后，再告诉 ChatGPT。
3. 不想继续时，双击“停止电脑助手.bat”。它只会关闭本助手自己的进程，不会关闭其他 Python、Node 或终端。
4. 紧急情况下按 Ctrl + Alt + Pause。若这个快捷键被占用，状态窗口会显示回退快捷键 Ctrl + Alt + F12。
5. 紧急停止后，远程请求不能恢复；只能在任务栏托盘的 Grayson电脑助手图标中选择“本地恢复控制”，或在本机运行恢复命令。
6. 输入密码、付款、充值或处理微信/QQ等私人聊天时，不要开放远程控制。程序也会拦截已识别的密码框、支付页和私人聊天窗口。
7. 双击“查看运行状态.bat”可查看服务、连接、控制状态、前台窗口和最近错误。
8. 日志位于本文件夹的 logs 子目录。UI 动作日志不会保存输入的完整文本，只记录长度和摘要。
9. 如果提示依赖缺失，双击“安装或修复依赖.bat”。

颜色说明
--------
绿色：允许远程查看和鼠标键盘控制
黄色：只允许查看窗口、截图和 UIA 控件
红色：紧急停止，必须在本机明确恢复

已知限制
--------
- UAC 安全桌面、锁屏界面和更高权限窗口无法也不应该被远程控制。
- 自绘游戏编辑器可能不提供完整 UI Automation 控件；此时仍可使用截图和物理像素坐标操作。
- 窗口截图捕获的是屏幕上当前可见像素；被遮挡或最小化的窗口需先恢复到前台。
- 不包含 OCR、录屏、语音、自动发布、支付、密码输入、注册表或任意 PowerShell 工具。
